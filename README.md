# 🏋️ Meus Treinos

App (PWA) da minha ficha de treino da academia — visual, offline e instalável no celular.

## Recursos
- 5 treinos (A–E) com todos os exercícios, séries, repetições e descanso
- Imagem animada da execução de cada exercício ("GIF" de 2 frames)
- Marcar séries feitas com barra de progresso
- Cronômetro de descanso (com som e vibração ao terminar)
- Registro de carga por exercício (salvo no aparelho)
- Funciona offline (Service Worker) e pode ser instalado na tela inicial

## Como editar os treinos
Toda a ficha fica em [`treinos.js`](treinos.js) — é só editar os exercícios seguindo o modelo do arquivo.

## Como instalar no celular
Abra o link do GitHub Pages no navegador do celular → menu → **"Adicionar à tela inicial"**.
